# 🚆 Railway Reservation System

## About The Project
This is a Single Page Application (SPA) built for my college project. It allows users to search for trains, book tickets, and view their booking history. 

## Features
* **Train Search:** Search available trains by Source and Destination.
* **Ticket Booking:** Auto-generates a unique PNR number.
* **Seat Management:** Available seats decrease automatically when a ticket is booked.
* **Local Database:** Uses the browser's Web Storage API (`localStorage`) so bookings are saved permanently even if the page is refreshed.

## Technologies Used
* HTML5
* CSS3
* JavaScript (ES6)
* LocalStorage API
